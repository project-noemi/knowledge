# Importált diák

A `src` attribútummal több fájlra bonthatod a slides.md fájlt, és tetszőlegesen rendezheted őket.

#### `slides.md`

```markdown
# 1. oldal

A 2. oldal a fő belépési pontból.

---

## src: ./subpage.md
```

<br>

#### `subpage.md`

```markdown
# 2. oldal

A 2. oldal egy másik fájlból.
```

[További információ](https://sli.dev/guide/syntax.html#importing-slides)
