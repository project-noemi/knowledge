# The Data Problem

<v-clicks>

- Most business data lives in spreadsheets — but few people can analyse it deeply
- Writing Excel formulas and SQL queries takes skill and time
- Turning raw data into insights requires expertise most teams don't have
- Data analysts are a bottleneck — you can't wait days for a simple answer

</v-clicks>

<v-click>

AI lets anyone ask questions of their data in plain language.

</v-click>

transition: slide-up

# What You Can Do Without Code

<v-clicks>

- **Ask questions** — "Which product had the highest return rate last quarter?"
- **Spot trends** — "Is there a seasonal pattern in this sales data?"
- **Generate charts** — "Create a bar chart of revenue by region"
- **Clean data** — "Remove duplicates and standardise the date format"
- **Write formulas** — "Write an Excel formula to calculate 30-day rolling average"
- **Summarise** — "Give me a 5-bullet executive summary of this dataset"

</v-clicks>

# ChatGPT Advanced Data Analysis

Upload any file (CSV, Excel, PDF) and ask questions in plain English.

<v-clicks>

- Available in ChatGPT Plus (GPT-4o)
- Runs actual Python code behind the scenes
- Can produce charts, pivot tables, correlations
- Handles messy, real-world data

</v-clicks>

<v-click>

**Example:**
> "I've uploaded our Q3 sales data. Which sales rep had the best conversion rate, and what was it?"

</v-click>

# Google Sheets AI Features

<v-clicks>

- **Help me organise** — describe a table you need and it builds it
- **Formula suggestions** — start typing and Sheets suggests the formula
- **Gemini sidebar** — ask questions about your sheet in natural language
- **Smart fill** — learns patterns and auto-fills columns

</v-clicks>

<v-click>

**Example:**
> Select a messy column and ask Gemini: "Clean this list — standardise capitalisation and remove trailing spaces"

</v-click>

# Getting Formulas Written for You

Instead of memorising syntax, describe what you want:

<v-clicks>

**VLOOKUP alternative:**
> "Write an Excel formula to look up the price for a product code in column A, using a reference table on Sheet2"

**Conditional calculation:**
> "Write a formula that sums column C only where column B equals 'London'"

**Date logic:**
> "Write a formula that calculates the number of working days between two dates"

</v-clicks>

<v-click>

Paste the formula, test it, ask AI to explain it if needed.

</v-click>

# Cleaning Messy Data

Real-world data is always messy. AI can help:

<v-clicks>

- **Standardise formats** — dates, phone numbers, addresses
- **Find and flag anomalies** — "Are there any outliers in this revenue column?"
- **Split columns** — "Separate full name into first and last name columns"
- **Categorise text** — "Group these customer feedback comments into themes"
- **Deduplicate** — identify and remove duplicate rows

</v-clicks>

# Building Reports Automatically

<v-clicks>

1. Upload your raw data to ChatGPT
2. Ask: "Summarise the key findings in 5 bullet points for a management report"
3. Ask: "Generate a bar chart of monthly revenue and a line chart of growth rate"
4. Copy the insights into your report template
5. Ask: "Write an executive summary paragraph based on these findings"

</v-clicks>

<v-click>

A full report that took half a day now takes **30 minutes**.

</v-click>

# Asking the Right Questions

<v-clicks>

- **Compare:** "Which region performed best vs last year?"
- **Rank:** "What are the top 5 customers by revenue?"
- **Correlate:** "Is there a relationship between marketing spend and new customers?"
- **Forecast:** "Based on this trend, what would you expect next quarter?"
- **Segment:** "Group customers by purchase frequency and average order value"

</v-clicks>

<v-click>

> You don't need to know HOW to analyse — just know WHAT you want to know.

</v-click>
