# Why This Matters

Before picking a tool, you need to know what's out there.

<v-clicks>

- The AI tools market is **enormous and fast-moving**
- Most people only know 1–2 tools — and miss better options
- The right tool depends on **your task**, not the hype
- Many tools overlap — knowing the landscape saves time and money

</v-clicks>

<v-click>

> You don't need every tool. You need the **right tool for each job**.

</v-click>

# The Big Four — General AI Assistants

These do a bit of everything: writing, reasoning, coding, research.

| Tool | Made by | Best for |
|------|---------|----------|
| **ChatGPT** | OpenAI | Widest feature set, plugins, GPT Store |
| **Claude** | Anthropic | Long documents, nuanced writing, safety |
| **Gemini** | Google | Google Workspace integration, multimodal |
| **Copilot** | Microsoft | Office 365 integration, enterprise |

<v-click>

**How to choose:** Use ChatGPT for general tasks, Claude for long/complex documents, Gemini if you live in Google Workspace, Copilot if your company uses Microsoft 365.

</v-click>

# Writing & Content

<v-clicks>

- **ChatGPT / Claude / Gemini** — drafting, editing, rewriting any text
- **Notion AI** — write and summarise directly inside Notion
- **Jasper** — marketing copy, brand voice, campaigns
- **Copy.ai** — product descriptions, social posts, ad copy
- **Grammarly** — grammar, tone, clarity suggestions inline
- **Hemingway App** — readability and simplicity scoring

</v-clicks>

<v-click>

**Quick win:** Paste a rough draft into Claude and ask it to rewrite for clarity and a professional tone.

</v-click>

# Research & Knowledge

<v-clicks>

- **Perplexity AI** — AI-powered search with cited sources
- **NotebookLM** — upload your own documents and chat with them
- **Elicit** — research papers and literature review
- **Consensus** — find what the science says on any topic
- **ChatGPT + Browse** — live web search with AI reasoning

</v-clicks>

<v-click>

**Quick win:** Use Perplexity instead of Google when you need a synthesised answer, not just links.

</v-click>

# Image & Video Generation

<v-clicks>

- **Midjourney** — highest quality AI images, via Discord
- **DALL-E 3** — image generation inside ChatGPT
- **Adobe Firefly** — AI images that are safe to use commercially
- **Canva AI** — image generation + design tools combined
- **Runway** — AI video generation and editing
- **Sora** — OpenAI's video generation model
- **HeyGen** — AI avatar videos for presentations

</v-clicks>

<v-click>

**Quick win:** Use Canva AI for marketing assets — it keeps everything inside your existing design workflow.

</v-click>

# Coding & Development

<v-clicks>

- **GitHub Copilot** — AI code completion inside VS Code / JetBrains
- **Cursor** — AI-native code editor, full codebase context
- **v0 by Vercel** — generate UI components from a text description
- **Replit AI** — build and run apps in the browser with AI
- **Claude / ChatGPT** — explain code, debug, write scripts

</v-clicks>

<v-click>

**Quick win:** Even non-developers can use ChatGPT to write simple Excel macros, Python scripts, or automate repetitive tasks.

</v-click>

# Productivity & Meetings

<v-clicks>

- **Otter.ai** — transcribe and summarise meetings automatically
- **Fireflies.ai** — meeting notes + action items + search
- **Notion AI** — summarise notes, generate action items
- **Microsoft Copilot** — meeting summaries in Teams, drafts in Outlook
- **Reclaim.ai** — AI calendar management and focus time scheduling
- **Motion** — AI task and project scheduling

</v-clicks>

<v-click>

**Quick win:** Connect Otter or Fireflies to your Google Meet / Zoom — never manually write meeting notes again.

</v-click>

# Automation & Workflows

<v-clicks>

- **n8n** — open source visual workflow automation with AI nodes
- **Zapier** — connect apps with triggers and actions, AI steps included
- **Make (Integromat)** — visual automation, more powerful than Zapier
- **Relevance AI** — build AI agents without code
- **Lindy** — AI agent for email, calendar, and CRM automation

</v-clicks>

<v-click>

**Quick win:** Use Zapier to automatically summarise new emails and send the summary to Slack — zero code required.

</v-click>

# How to Pick the Right Tool

<v-clicks>

1. **Define the task first** — writing? research? image? automation?
2. **Check what you already pay for** — Copilot may be included in your Microsoft licence
3. **Start with the general assistants** — ChatGPT/Claude solve 80% of tasks
4. **Add specialist tools** for the remaining 20%
5. **Consolidate** — fewer tools = less context switching

</v-clicks>

# Summary

<v-clicks>

The AI tools market is vast — but most tasks are covered by **a handful of the right tools**

Start with **one general assistant** and get great at it

Add **specialist tools** only when you hit a real limit

The best tool is the one you **actually use**

</v-clicks>

<v-click>

*Know the map. Pick your route.*

</v-click>
